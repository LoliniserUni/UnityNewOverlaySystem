Unity Esports Team Stream WebApp

Important:

  • To use this, you require BakkesMod
  • And the SOS plugin
  • I recommend setting the SOS plugin to send data every 30ms (controlled through BakkesMod)

Contact me on Discord: loliniser

To use in OBS, create a browser source with dimensions 1920x1080 and use the URL for any of the scenes below:

  • http://localhost:5000/Booth/overlay - Normal 2 caster booth scene
  • http://localhost:5000/Booth3/overlay - 3 caster / interview scene
  • http://localhost:5000/BRB/overlay - Be Right Back scene
  • http://localhost:5000/Starting/overlay - Starting Scene
  • http://localhost:5000/Ending/overlay - Ending Scene
  • http://localhost:5000/ScoreBoard/overlay - Post match Scoreboard scene
  • http://localhost:5000/InGame/overlay - In game overlay (refresh source between series)
  • http://localhost:5000/controller - General scene settings controller
  • http://localhost:5000/gameController - Match related settings controller
